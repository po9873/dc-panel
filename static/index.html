🌐 Web Push 浏览器推送

不需要账号或密钥，点开启并允许浏览器通知即可。必须用 HTTPS 访问面板（浏览器规范限制，HTTP 或 IP 直连无法开启；可挂自有证书 PANEL_SSL_CERT / PANEL_SSL_KEY，或经 HTTPS 反代）。手机与电脑均可接收，关掉网页也能收到；iOS 需 Safari 16.4+ 并先「添加到主屏幕」。
